# 1,000-memory renewal exercise

The optimized migration took **13 minutes 54.1 seconds** on Sui/Walrus testnet.
The whole entry, including preparation and verification, took **15 minutes 13.7 seconds**.

| Measurement | Previous full run | Optimized full run |
| --- | ---: | ---: |
| Migration | 27m 23.9s | 13m 54.1s |
| Successful transactions | 2,000 | 2,000 |
| Gas and relay tips | 10.042977000 SUI | 10.042977000 SUI |
| Storage and write fees actually paid | 1.953668052 WAL | 2.227970052 WAL |

Observed migration time fell **49.26%** at the same 16 workers / 8 concurrent
transactions. All 1,000 memories completed in one attempt, without retries.

The dataset contained 4,226,290 ciphertext bytes, two synthetic owners and five
namespaces. The flow downloaded existing ciphertext and metadata, registered and
uploaded fresh Blob objects, certified and transferred them to their original
owners, then atomically updated the existing database mappings. No new source
data or vector rows were generated by the migration.

The optimized run included **1,000 cold metadata computations and cache writes**
using four encoding threads. A separate six-item cold/hot exercise verified
persistent cache reuse. Full warm-cache throughput has not been measured.

WAL increased by 0.274302000 because each item bought one additional epoch:
874 items went from five to six epochs, and 126 went from six to seven. At each
item's previous lease duration, the new WAL cost remains 1.953668052. Observed
storage unit and write prices were unchanged. The two small QA cycles separately
cost 0.120170988 SUI and 0.021383460 WAL.

Validation passed: 36 SQL checks, all 1,000 content hashes/metadata/owner mappings,
4,000 fresh Blob/metadata object reads, 20 original-owner decryption samples,
2,000 transaction digests and independent nonce/registration/upload checks.
The original 1,186 vector rows were preserved and there were no pending receipts.

This measures the testnet protocol plus a local database using synthetic data.
It does not measure production traffic, the service HTTP/auth/queue stack or MCP
notification delivery. Byte-identical ciphertext retains its Walrus blob ID;
the Sui Blob object and lease change. The benchmark used product source
`856fb01793fdb4301cc1b1a9c8673c4c55595f08` and pinned SDK versions documented in
the harness. Sequential runs may also differ because of network conditions.

Packaging replaces the benchmark operator's personal defaults with explicit
local operator configuration; it does not change the measured migration flow.
No live migration was rerun for packaging. Run receipts, private configuration,
keys, ciphertext and database files remain local and are excluded from Git.

See [the harness guide](../../tools/renewal-testnet/README.md) for reproduction.
